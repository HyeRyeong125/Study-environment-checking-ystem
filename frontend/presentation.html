📌 비전 & 문제 정의

🎯 우리의 비전

학생들의 집중력을 향상시키는
IoT 기반 학습 환경 모니터링 시스템

❌ 해결하려는 문제

  • 공부 중 집중력 저하를 실시간으로 감지하기 어려움
  • 학습 환경 요인(조도, 소음)을 체계적으로 파악할 수 없음
  • 개인화된 자동 피드백 시스템이 부재함

💡 우리의 솔루션

📡센서 데이터 수집

Arduino로 조도, 소음, 거리를 실시간으로 측정

🤖AI 기반 분석

MediaPipe와 EXAONE AI로 집중도를 똑똑하게 평가

📊대시보드 시각화

실시간 데이터와 AI 추천사항을 한눈에 확인

🔧 기술 스택

🛠️ Hardware

  • Arduino Uno
  • 조도 센서 (CdS)
  • 소음 센서
  • 초음파 센서

💻 Software

  • Python + Flask
  • MQTT Broker
  • HTML/CSS/JS
  • MediaPipe + AI API

시스템 아키텍처

Arduino → Serial → Gateway → MQTT → Backend API → Frontend Dashboard

⭐ 핵심 기능

1️⃣ 센서 데이터 실시간 수집

  • 🔆 조도 센서: 학습 환경 밝기 (0-1000 lux)
  • 🔊 소음 센서: 환경 소음 수준 (0-120 dB)
  • 📏 거리 센서: 사용자와의 거리 (0-400 cm)

2️⃣ AI 기반 집중도 분석

  • 얼굴 감지 및 시선 추적
  • 자세 분석을 통한 집중 상태 평가

3️⃣ 개인화된 추천사항

  • EXAONE AI로 맞춤형 개선 방안 제시

🏗️ 시스템 아키텍처

┌─────────────┐ │ Arduino │ ← 센서 데이터 └──────┬──────┘ │ Serial ↓ ┌──────────────────────┐ │ Arduino Gateway │ ← MQTT 게이트웨이 └──────┬───────────────┘ │ ↓ ┌──────────────────────┐ │ MQTT Broker │ ← 메시지 브로커 └──────┬───────────────┘ │ ↓ ┌──────────────────────┐ │ Flask Backend │ ← REST API └──────┬───────────────┘ │ ↓ ┌──────────────────────┐ │ Frontend Dashboard │ ← 웹 대시보드 └──────────────────────┘

💫 실시간 데이터 흐름: 센서에서 대시보드까지 1초 이내 전달

📅 프로젝트 진행 과정

✅ 완료한 작업

  • Arduino 센서 연동 및 스케치 개발
  • MQTT 기반 실시간 데이터 전송
  • Flask REST API 구축
  • Frontend 대시보드 개발

🔧 극복한 기술적 과제

  • 센서값 변환: ADC 원본값(0-1023) → 실제 단위(dB, lux)
  • MQTT 토픽 최적화: 데이터 타입별 토픽 분리
  • 실시간 동기화: Backend-Frontend 포트 일치 및 CORS 설정

📊 구현 결과

대시보드 주요 기능

  • 🔆 실시간 조도값 표시 (lux 단위)
  • 🔊 실시간 소음도 표시 (dB 단위)
  • 🎯 집중도 점수 시각화 (0-100%)
  • ⏱️ 포모도로 타이머 (집중 + 휴식)
  • 💡 AI 기반 추천사항
  • 📈 통계 및 분석

🔬 기술 하이라이트

• 마이크로폰: (ADC / 1023) × 120 = dB

• 조도: (ADC / 1023) × 1000 = lux
