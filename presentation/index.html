🏗️ 시스템 아키텍처

4-Layer Architecture

🔧 Hardware Layer (Arduino)

센서 구성:

  • 📳 진동 센서 - 타이핑/사용 패턴 감지
  • 💡 조도 센서 - 실내 조도 감지
  • 📏 초음파 센서 - 자세 감지 및 거리 모니터링

통신: MQTT / Serial → JSON 형식

⚙️ Backend Layer (Python)

주요 모듈:

  • 📡 API 서버 - REST API 엔드포인트 제공
  • 🔄 센서 서비스 - 데이터 수집 및 처리
  • 📊 데이터 서비스 - 분석 및 통계
  • 🤖 AI 서비스 - EXAONE AI 통합
  • 📦 데이터 모델 - Sensor, User, Statistics

🎨 Frontend Layer (Web)

페이지 & 기능:

  • 📊 Dashboard - 실시간 센서 데이터 모니터링
  • 📈 Stats - 집중 시간, 환경 통계 분석
  • ⚙️ Settings - 사용자 설정

기술:

  • Chart.js - 실시간 데이터 시각화
  • MediaPipe - 포즈/얼굴 감지
  • MediaDevices API - 웹캠 접근

💾 Database Layer

환경 데이터베이스 용도
개발 H2 (인메모리) 자동 생성, 빠른 개발
프로덕션 MySQL 안정적인 데이터 저장

주요 테이블:

  • sensors - 센서 데이터
  • users - 사용자 정보
  • statistics - 통계 데이터

데이터 흐름

Arduino 센서 데이터
↓ MQTT/Serial
Python Backend 데이터 처리
↓ 저장 & 분석
Database 데이터 보관
↓ REST API
Web Frontend 실시간 대시보드
↓ 시각화
사용자 모니터링 & 피드백
