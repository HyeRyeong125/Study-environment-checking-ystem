Structure · WBS

작업 분류 체계 (4계층)

1 · Hardware

Arduino 센서 수집 — 조도(lux), 소음(dB), 동작 감지

2 · Backend

Python/Flask — 데이터 처리, REST API, AI 통합

3 · Frontend

웹 대시보드 — 모니터링, 통계, 포모도로

4 · Database

데이터 저장 — H2(개발) / MySQL(프로덕션)

Q&A · Structure

앱의 디렉토리 구조

앱프_프젝/
├── backend/              # Python Flask 서버
│   ├── app/services/     # 비즈니스 로직
│   │     sensor_service · ai_service · data_service
│   ├── app/api/routes.py # REST API
│   ├── main.py           # 진입점
│   └── arduino_gateway.py# 시리얼 통신
├── frontend/             # 웹 대시보드
│   └── src/ (pages · css · js)
└── arduino/              # 펌웨어
      sensor_sketch.ino
Q&A · Setup

개발 환경 설정

① Python 환경

cd backend  →  pip install -r requirements.txt

② MQTT 브로커

brew install mosquitto  →  mosquitto 실행

③ Arduino

Arduino IDE에서 sensor_sketch.ino 업로드

④ 환경 변수

.env — 시리얼 포트, MQTT 브로커, PORT 설정

Q&A · Quick Start

설치 및 실행 가이드

# 1. 클론
git clone .../Study-environment-checking-system.git

# 2. 의존성
cd backend && pip install -r requirements.txt

# 3. 환경 설정
cp .env.example .env   # 포트 등 수정

# 4. 실행
mosquitto & python arduino_gateway.py & python main.py
# → http://localhost:3000
